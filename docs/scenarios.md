# Scenarios

Every behavior the owner relies on, and what proves it. `test/scenarios.test.ts` fails when a backticked test title below no longer starts a test in `test/`, or when a row has no proof.

Proof kinds:

- A backticked title prefix is a test that runs in `npm test`.
- `eval Rnn` is a real-message case in the owner's private eval (`npm run eval:real`). Its labels live outside the repo because they quote real chats.
- `live <file>` is a live run on real Teams with its steps and evidence in that file.
- `manual:` is followed by the steps to run by hand.
